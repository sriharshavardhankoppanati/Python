# 🐍 Python – Strings & Tuples

A beginner-friendly Python program demonstrating basic **String and Tuple operations**.

## 📌 Concepts Covered

### 🔤 Strings

* Concatenation
* Indexing & Slicing
* Reverse String
* `upper()`, `lower()`, `capitalize()`
* `count()` & `replace()`

### 📦 Tuples

* Tuple Creation
* Concatenation
* Repetition
* Indexing
* Slicing

## 🛠️ Tools

* Python 3
* VS Code

## ▶️ Run

```bash
python strings_tuples.py
```

📚 **Focus:** Practicing Python fundamentals and data structure operations.
