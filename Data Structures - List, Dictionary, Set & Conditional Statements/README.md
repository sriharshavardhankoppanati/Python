# 🐍 Python Data Structures & Conditional Logic

A practical Python project demonstrating the use of **Lists, Dictionaries, Sets, Operators, and Conditional Statements** through simple data manipulation and performance classification programs.

## 📌 Concepts Covered

* 📋 **Lists** – Creation, indexing, modification, append, insert, remove, pop, extend, sorting, and aggregation.
* 📖 **Dictionaries** – Creating key-value pairs, accessing and updating values, and using `keys()`, `values()`, and `items()`.
* 🔤 **Sets** – Unique values, immutability, union, and intersection operations.
* 🔀 **Conditional Statements** – Using `if`, `elif`, and `else` for decision-making.
* ➕ **Operators** – Applying comparison and logical operations.
* ⌨️ **User Input** – Accepting and validating a performance score from the user.

## 🎯 Key Features

* Manipulates and accesses list elements using different methods.
* Works with student marks using dictionary operations.
* Demonstrates how sets automatically remove duplicate values.
* Shows why individual set elements cannot be accessed or modified using indexes.
* Performs union and intersection between sets.
* Categorizes a score into **Above Average, Average, or Below Average**.
