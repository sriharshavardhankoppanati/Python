# 📊 Survey Feedback Analyzer

## 📌 Project Overview
The **Survey Feedback Analyzer** is a Python-based project that analyzes customer feedback using text cleaning, word counting, and rating analysis. It applies core Python concepts to transform raw feedback into meaningful insights.

## 🎯 Features
- 📝 Preloaded feedback records and user input for new feedback.
- 🧹 Text cleaning: removes punctuation, extra spaces, and uppercase letters.
- 🔍 Counts feedback containing specific words such as *good*, *poor*, and *excellent*.
- ⭐ Calculates the average, highest, and lowest ratings.
- 📈 Displays rating distribution and customer satisfaction categories.
- 💬 Identifies the longest feedback comment.
- 🔤 Extracts and sorts unique words alphabetically.
- ↕️ Sorts feedback records by rating from highest to lowest.
- ✅ Validates user inputs and ratings.

## 🛠️ Technologies Used
- **Language:** Python
- **Concepts:** Lists, Dictionaries, Loops, Conditional Statements, Functions, Strings, Sets, `zip()`, and `sorted()`

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

   ```bash
   python Survey_Feedback_Analyzer_Enhanced.py
   ```

4. Enter the number of additional feedback records and provide the requested details.
5. Review the generated analysis and summary.
