# 🐍 Python Fundamentals – Loops and Functions

This repository contains Python programs demonstrating the practical use of loops, control statements, and functions.

## 📌 Programs Included

### 1. 🎯 Number Guessing Game
- Generates a random number between 1 and 10.
- Allows up to three valid guesses.
- Provides feedback for guesses that are too high or too low.
- Demonstrates `while`, `else`, `break`, `continue`, and `pass`.

### 2. ✖️ Multiplication Table Generator
- Takes a number as input from the user.
- Generates its multiplication table from 1 to 10.
- Uses a `for` loop and the `range()` function.

### 3. 📊 BMI Calculator
- Calculates Body Mass Index (BMI) using weight and height.
- Uses a custom function with parameters and a return value.
- Displays the result rounded to two decimal places.

## 🛠️ Technologies Used
- **Language:** Python
- **Editor:** Visual Studio Code

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run any program using:

```bash
python "Number Guessing.py"
python "Multiplication table generator.py"
python "BMI Calculator.py"
```

## 🎯 Learning Outcomes
- Understanding `while` and `for` loops.
- Applying Python control statements.
- Creating and calling functions.
- Working with user input, random numbers, and calculations.
